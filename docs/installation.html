Installation

Requirements#

  • Blender 5.2 or newer.
  • Rigify for rig generation. It ships with Blender but may need to be enabled manually.

In AetherBlend's preferences, Additional Plugins shows Rigify as required for rig generation, with Meddle Tools and FFGear optional for their shader integrations. Missing means not installed; Inactive means installed but disabled in Blender. Use Enable to activate an installed plugin. FFXIV tools are available without choosing a feature set.

Feature toggles#

Open AetherBlend's preferences and select Features to enable or disable Import / Export, Rig Generator, Rig Edit, Rig UI, and Shaders. Changes take effect immediately and are kept when you save Blender's preferences. Disabled features unregister their tools, panels, and properties without deleting saved rig or export settings.

Rig Edit and Rig UI require Rig Generator. Enabling either also enables the generator; disabling the generator turns both off. Import / Export and Shaders can be toggled separately.

Drag and drop#

The quickest way. Drag a button below into an open Blender window.

  1. Drag the AetherBlend button into Blender. The first time, Blender asks to add the AetherBlend repository, confirm it.
  2. Drag the same button a second time to install the add-on from that repository.
  3. Meddle Tools and FFGear come from the same repository, so once it is added they need only one drop each.
Required Drag AetherBlend into Blender

The add-on itself. Drop it twice: first to add the repository, then to install.

Recommended Drag Meddle Tools into Blender

Needed only for Meddle shader import. You can skip it for model import and rigging.

Optional Drag FFGear into Blender

Extra gear shaders. Not needed for AetherBlend to work.

All three buttons use the shared FFXIV Blender Plugins repository. Because it is a repository, Blender keeps the installed add-ons updated afterwards.

If dragging does nothing, use one of the methods below.

Repository feature#

  1. In Blender's preferences menu, select the "Get Extensions" tab
  2. Select the repositories drop-down-menu in the top right of the window
  3. Select "Add Remote Repository"
  4. Paste the following URL into the required repository field:
https://raw.githubusercontent.com/ShinoMythmaker/FFXIV-Blender-Plugins/refs/heads/main/repo.json
  1. Select Check for Updates on Startup.
  2. Select Create.
  3. Find AetherBlend in the list of available add-ons and install it

Using this feature will allow Blender to automatically keep AetherBlend up to date.

Manual#

  1. Download the newest .zip here
  2. Open your preferences menu in Blender and navigate to the add-ons section
  3. From the dropdown in the top right of the window, select "Install from Disk" and navigate to your downloaded release of AetherBlend
