<h2>What is AetherBlend?</h2>

<p>AetherBlend is a plugin for Blender built to allow the animation of character models from Final Fantasy XIV. It generates an armature using custom rigging and existing rig types provided by Blender's Rigify add-on. The generation process is dynamic and thus highly compatible with most player character and humanoid non-player character armatures. AetherBlend was built with modding in mind, meaning that poses and animations created using it can easily be imported into the game using existing tools such as Brio, XAT and VFXEditor.</p>

<p>Our goal is to make custom FFXIV characters animation-ready in Blender: generate a character-scaled, industry-standard rig while preserving modding and GPosing support. AetherBlend also includes tools for FFXIV VFX creation.</p>
