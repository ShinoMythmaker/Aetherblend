The Template System

The Template System#

The template system serves to provide a more modular foundation for rig generation that provides greater control and variation in different elements of the control rig. By default AetherBlend loads the 'Dynamic' template which contains a preset list of modules it will attempt to generate on the target armature.

If you want to customise this, select 'Custom' from the template drop-down menu. You'll be faced with an empty list you can populate manually or by selecting the 'populate' button and choosing from existing templates. For now that will only be 'Dynamic', but custom templates you save will also appear here.

Not all modules currently have alternatives available, but you're free to make suggestions. For example, the tail module has two options: 1. A spline based tail with FK switch 2. A fully FK tail with no extra functionality

Saving your custom template#

You can save your custom template to re-use it at any time from the template drop-down. Templates are saved as .json files, so you can easily share them should you want to.

You are also able to change your default template to any other template you've created in the add-on preferences.
